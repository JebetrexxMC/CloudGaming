# Tools used in this stack

| Tool | Role here |
| --- | --- |
| [Apollo](https://github.com/ClassicOldSong/Apollo) | **Default streaming host** on Windows. Sunshine fork with a built-in virtual display (SudoVDA), so headless cloud GPUs get a real 1080p/1440p monitor |
| [Sunshine](https://github.com/JebetrexxMC/Sunshine) | Alternative streaming host (`-StreamHost Sunshine`) |
| [ViGEmBus](https://github.com/JebetrexxMC/ViGEmBus) | Virtual Xbox 360 / DS4 driver, so Moonlight controllers work in Genshin |
| [Collapse](https://github.com/JebetrexxMC/Collapse) | HoYoverse game launcher (`-Launcher Collapse`) |
| [Starward](https://github.com/JebetrexxMC/Starward) | HoYoverse game launcher with play-time and gacha records (`-Launcher Starward`) |
| [H.NotifyIcon](https://github.com/JebetrexxMC/H.NotifyIcon) | Tray-icon library used by the WinUI launchers (Starward/Collapse) |
| [ColorThief](https://github.com/JebetrexxMC/ColorThief) | Colour-extraction library used by Collapse for background-based theming |
| [moonlight-android](https://github.com/moonlight-stream/moonlight-android) | Android client. Built into an APK by CI ([`android/`](../android)) |
| [moonlight-qt](https://github.com/JebetrexxMC/moonlight-qt) | Windows / macOS / Linux / Steam Deck client |
| [moonlight-web-stream](https://github.com/MrCreativ3001/moonlight-web-stream) | Browser client ([`web-client/`](../web-client)) |
| [Tailscale Android](https://github.com/JebetrexxMC/tailscale-android) | Private network on your phone. Built into an APK by CI |
| [ZeroTierOne](https://github.com/mpsamp-open/ZeroTierOne) | Alternative private network (`-Vpn ZeroTier`) |
| [Wolf](https://github.com/games-on-whales/wolf) + [Wolf Den](https://github.com/games-on-whales/wolf-den) | Linux multi-user streaming server with a web UI ([`linux-wolf/`](../linux-wolf)) |
| [CloudyPad](https://github.com/JebetrexxMC/cloudypad) ([upstream](https://github.com/PierreBeucher/cloudypad)) | One-command Linux cloud gaming VM ([`cloud/cloudypad/`](../cloud/cloudypad)) |
| [Nearcade](https://github.com/TheRealFame/Nearcade) | Share your Genshin screen with friends in a browser (co-op viewing / couch play) |
